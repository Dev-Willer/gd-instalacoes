# GD Instalações Elétricas

Site React + Vite + Tailwind CSS para Gabriel e Romário, de Betim/MG.

## Cloudflare Pages
- Build command: `npm run build`
- Output directory: `dist`
- Framework: React (Vite)

## Imagens
O projeto usa fotografias reais do cliente em `public/images/`. **As imagens ainda precisam ser enviadas** ao repositório, porque o conector do GitHub não suporta envio dos binários locais nesta sessão.
O pacote completo com as fotos está disponível no arquivo ZIP fornecido na conversa.

## Cuidados antes de anunciar
- Confirme informações de avaliação (5,0 e 18 avaliações) no Google.
- Configure domínio, favicon, Search Console e medição de conversões.
- Teste botões de WhatsApp e ligação em celular.
